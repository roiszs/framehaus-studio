# FrameHaus Studio — Portfolio Case Study

## Descripción corta en español

Website premium bilingüe desarrollado para un estudio ficticio de fotografía y video profesional. El proyecto integra servicios, portafolio visual, paquetes comerciales, páginas detalle, flujo de solicitud de sesión, diseño responsive, animaciones con Motion y estructura SEO. Diseñado como una experiencia comercial moderna para mostrar cómo FronteraCode puede construir websites visuales, funcionales y listos para negocios creativos reales.

## Puntos clave

- Website bilingüe ES/EN.
- Desarrollado con Next.js, React, TypeScript y Tailwind CSS.
- UI premium con shadcn/ui, lucide-react y Motion.
- Servicios, paquetes, portafolio y páginas detalle.
- Flujo de solicitud de sesión.
- Diseño responsive.
- Metadata, sitemap y robots.
- Proyecto desarrollado como caso de estudio para FronteraCode.
